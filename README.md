## 🎨 Design & Architecture

- **Aesthetic**: Minimalist executive product design with generous whitespace, subtle borders, soft shadows, and clean neutral/slate surfaces.
- **Color Theme**: Clean dark and light surfaces with calm sky blue (`#0284c7`) and emerald accents + responsive theme switcher.
- **Typography**: Plus Jakarta Sans & Inter with JetBrains Mono for code snippets.
- **Tech Stack**: React 18 + TypeScript + Vite + Tailwind CSS.
- **Deployment**: Zero-configuration static hosting on GitHub Pages via automated GitHub Actions.

## 🛠️ Local Development & Build

```bash
# Clone the repository
git clone https://github.com/Safeer-Hussain/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Run TypeScript checks and build production bundle
npm run build

# Preview production build locally
npm run preview
```
