## ⚡ Architecture & Tech Stack

This developer portfolio is engineered as an ultra-fast, zero-overhead static web application designed for zero-configuration deployment on GitHub Pages (`https://safeer-hussain.github.io`).

- **Core Framework**: React 18 + TypeScript (Strict Type Safety)
- **Styling**: Tailwind CSS with custom terminal blueprint grid & glassmorphism
- **Design Aesthetic**: High-craft dark-mode engineering terminal / architectural blueprint theme (`#0B0F19`, emerald `#10B981` & cyan `#06B6D4` luminous accents, Inter + JetBrains Mono typography) with instant light-mode toggle.
- **Performance**: Sub-100kB gzipped production bundle, <1s First Contentful Paint, zero client-side routing runtime overhead.
- **Responsiveness**: 100% responsive from 360dp mobile viewports up to 4K ultrawide desktop monitors.

## 🛠️ Local Development & Build

```bash
# Clone the repository
git clone https://github.com/Safeer-Hussain/Safeer-Hussain.github.io.git
cd Safeer-Hussain.github.io

# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript typechecks & build static bundle
npm run build

# Preview production build locally
npm run preview
```

## 🚀 Automated Deployment

Every push to the `main` branch triggers the GitHub Actions workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) which:
1. Installs dependencies (`npm ci`)
2. Verifies TypeScript types and builds the static bundle (`npm run build`)
3. Deploys zero-overhead static assets directly to GitHub Pages (`https://safeer-hussain.github.io`).
